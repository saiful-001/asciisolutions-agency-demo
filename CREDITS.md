# Credits & licenses

## Images
All images in `assets/images/` (hero art, service illustrations, portfolio mockups, team avatars, about illustration, logo, favicon) are **original SVG artwork generated for this project**. There are **no third-party photos or stock images**, so there is nothing to attribute and no licence restriction on them. `assets/images/og/og-default.png` is also generated for this project.

> No stock photos were downloaded: the environment this project was built in could not reach image sources such as Unsplash, Pexels or Pixabay, so original SVG illustrations were used instead (as the brief allows). If you later add photos, add each one here with source URL, author and licence. Avoid identifiable faces and trademarked logos unless the licence clearly allows it.
